# Virtual Piano Project

## 🎹 Project Overview

This is a beginner-level **Virtual Piano** project designed to provide a pleasant user interface for users, along with authentication features. The project allows users to play a virtual piano using their keyboard and download their play sequence as a sound recording. It provides an engaging and interactive way for users to enjoy music and learn piano keys.

## 💡 Features

- **User Authentication**: Users can create an account, log in, and have their own personalized piano experience.
- **Piano Key Sounds**: Different sound files for each piano key are included to simulate real piano tones.
- **Download Notes**: Registered users can download their played sequence as a sequential sound recording.

## 🗂️ Project Structure

The project is organized into the following main folders:

### 1. **views**:
   - Contains HTML files responsible for the frontend user interface, such as the login page, home page, and piano key layout.

### 2. **statics**:
   - Contains **CSS** and **JavaScript** files that style the app and implement the logic for piano key interactions.
   
### 3. **models**:
   - Contains **PHP** files that handle the database interaction. These include files for authentication and saving user data.

### 4. **key_sounds**:
   - A folder containing all the audio files corresponding to each piano key sound that gets triggered when a user presses a key.
